代码领读

handle 按 op 分派。gain 读整型 kp（0..200），torque 读布尔 on。两者都调用 _apply_gains，再回空对象。

hello 校验 protocol 与 joints。官方 body_server 通常只验 protocol；本仓多验关节数，握手更严。

bus_order 把 14 维关节序扩成 15 槽，嘴位补 0。write 要求长度正好 15。

sensors 把世界重力旋进 trunk 系，直立时约 [0,0,-1]。响应里仍带教学回显 gain/torque/body_pos。

push 给躯干加水平速度；body 只查位置不步进。二者不是官方 op，验收脚本仍依赖它们。

1. daemon 调用 set_gain(50)。线上 JSON 应是哪项？（A）{"op":"set_gain","gain":50}　（B）{"op":"gain","kp":50}　（C）{"op":"gain","gain":50}　（D）{"op":"kp","value":50}

答案：B。方法名仍是 set_gain。线协议 op 是 gain，字段是 kp。见 impl/src/io.rs:375-381。

2. 客户端发送 {"op":"set_torque","on":false}。仿真应如何响应？（A）卸力并回空对象　（B）回 unknown op 错误　（C）静默忽略　（D）自动改写成 torque

答案：B。无兼容层。旧 op 必须立即失败，验收据此证明已不再说旧名。

3. 直立时 read 的 imu.gravity 约为 [0,0,-1]。该向量在哪个坐标系？（A）世界系　（B）trunk 系　（C）脚掌系　（D）相机系

答案：B。sensors 把世界重力旋进躯干系。见 impl/sim/duck_body.py:294。

4. 验收脚本调用 op=body 测位移。相对官方协议，这属于哪类？（A）官方必选 op　（B）教学附加帧　（C）PROTOCOL=2 新字段　（D）慢速传感面

答案：B。push/body 与 read 回显是教学附加。官方 serde 忽略未知字段；本仓验收依赖它们。

5. 本课收敛 D4 后，哪项仍故意不做？（A）钉死 PROTOCOL=1　（B）实现 slow/tof　（C）15 槽含嘴　（D）旧名必须失败

答案：B。决定采用备选 1：不扩 slow/tof，不把 currents_ma 做成必填。慢速传感仍归 D12→M10。
