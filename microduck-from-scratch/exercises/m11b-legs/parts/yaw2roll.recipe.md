# 作图配方 · yaw2roll（偏航转横滚，FT v2.2）

> 参考 Onshape 导入件：`import-log.json` → `yaw2roll_偏航转横滚-FT.SLDPRT`
> 仓内 `99-yaw_roll_motion_*.section.json` 是**另一件**（运动连杆，34×35.9×22.5），不要拿来画 yaw2roll。
> 下列尺寸来自官方仿真 STL 换算到 mm（与 FT 逆向外形接近，但以导入件 Measure 为准）。

## 0. 一句话结论

yaw2roll 是 **约 23 × 26 × 20.5 mm** 的偏航→横滚过渡件，一端接髋 yaw、一端接 roll 叉。
**必须一致**：总体包围盒、两端连接孔/槽的直径与中心距。
**可以近似**：过渡曲面（±1 mm）。

## 1. 包围盒（官方 STL → mm）

| 轴 | 范围 | 跨度 |
|---|---|---|
| x | 6.000 → 29.000 | 23.000 |
| y | −13.300 → 12.500 | 25.800 |
| z | −5.000 → 15.500 | 20.500 |

作图时建议把零件挪到更顺手的原点（例如把某个连接孔圆心放到 Origin），再把上表整体平移。

## 2. 关键切面提示（官方网格，仅作形状直觉）

| z (mm) | 现象 |
|---|---|
| 0 | 两块对称小截面（≈24 mm² ×2）——靠近一侧连接端 |
| 5 | 单块宽截面（≈90 mm²，x 跨满 6–29）——主体板 |
| 10 | 大外轮廓 + 四个小挖空（≈15 mm²）——腹板开孔区 |
| 13.5 | 两侧耳状截面 + 中部大环——另一端叉/耳 |

FT 导入件若特征树是实体，优先 **Measure 孔与壁厚**；若是网格/Composite，对着看外轮廓再参数化重画。

## 3. Onshape 作图步骤

1. 打开 `yaw2roll_偏航转横滚-FT`，确认 Parts 是实体还是 Composite。网格件不直接当最终件，只当尺子。
2. Measure 并记下（写进本目录笔记即可）：
   - 总长 / 总宽 / 总厚
   - 两端圆孔或腰孔的直径、孔心距
   - 壁厚最小值
3. 新建 PartStudio `yaw2roll`：先画**主体腹板**（矩形或圆角矩形）→ Extrude 到测得厚度。
4. 两端用 Sketch + Extrude/Revolve 做出连接耳；孔用圆切出，尺寸钉死。
5. 腹板开孔按参考位置挖；外缘过渡允许近似。
6. 与参考件并排 Measure：包围盒差 ≤0.5 mm，连接孔中心距差 ≤0.2 mm。

## 4. 验收口径

- **硬指标**：连接孔直径与中心距；厚度；与 hip_l / upper_leg 装配时不干涉的关键面。
- **软指标**：外轮廓 ≤1 mm。
- **不做**：仿真 STL 上的简化棱边、与装配无关的内部镂空 1:1。
