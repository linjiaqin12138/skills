同一个"现在"，两种未来：last_action 为什么有用

两个局面走到 now（第 10 拍）时，舵机位置完全相同（都是 0.000）。 但 A 的滤波器是静止的，B 的滤波器刚被一记 +0.63 的大命令拽起来、内部还留着 +0.18 的"惯性"—— 接下来几拍 B 会被滤波器继续往前推，A 原地不动。
策略若只看当前位置，A 和 B 无法区分；看到 last_action 才知道自己处在哪个局面。 链条：action → α=0.7 低通（橙）→ 舵机滞后 p=0.8f+0.2p（蓝）。
⚠️ 已知简化：本例舵机只有一阶，now 时刻两局面的 vel 实际不同（A=0, B=+0.72），pos+vel 联立也能区分—— 真实舵机是二阶以上且 vel 带噪，那时才轮到 last_action 补上解不开的那个状态（见 Q36）。
