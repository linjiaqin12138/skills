IMU 演示：动起来时，gyro / gravity / quat 各怎么变

躯干坐标系：x 朝前、y 朝左、z 朝上（和项目 src/io.rs 的 ImuData 同一套约定）。 左边鸭子按预设自己动，或者切手动拖滑块；右边三组数是这颗想象中的芯片每一拍读到的东西，下面是最近 4 秒的波形。

盯住一件事就够了：角速度只在"正在转"时非零，停住立刻归零；gravity 管"歪没歪"，停住了也留在坡上。这是三组数里最容易搞混的一条。

gyro[3] · 角速度

我现在转多快。停住就归零——哪怕人还歪着。

gravity[3] · 投影重力

重力相对我指向哪。歪了就变，停着也在。直立 = [0, 0, -1]（指向脚）。

quat[4] · 姿态四元数（wxyz 序）

姿态的打包形式：绕一根轴转一个角度收成四个数。w 接近 1 = 没怎么转；w 到 0 = 转了 180°。
