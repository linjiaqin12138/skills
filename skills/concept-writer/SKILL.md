# concept-writer

把一个概念写成一页，供以后链接。对话里当下的「听不懂」用 explain-it；要落盘的页用本 skill。

## 先选模式

看调用里的「模式」，读完本页后只打开对应文件。

| 调用里写的 | 打开 |
|---|---|
| 简单，或没写模式 | `simple.md` |
| 中等 | `medium.md` |
| max | `max.md` |

没写模式就做简单模式。概念看起来适合做图，也不自行升到中等或 max。

## 调用方要给的

缺了先问，再动笔。

- 模式：简单 / 中等 / max
- 核心问题：这一页只回答一个
- 目标读者已经知道什么
- 已核实的事实、公式、代码或素材。缺关键事实先问，不用通用知识编项目事实
- 输出路径。没给时：简单模式写 `docs/concepts/<slug>.md`；中等和 max 写 `docs/concepts/<slug>/<slug>.draft.md`，渲染到同目录 `<slug>.html`，素材进 `assets/`
- 概念与项目的关系（可选）。简单模式有这段才写「回到项目」
- 偏好文件路径（可选）。给了就先读

## 三种模式都遵守

- 一页一个核心问题
- 事实核实过再写。推断标【合理推断】
- 不编造链接、公式、命令输出
- 不改项目实现代码，不写里程碑教程正文
- 已有另一种格式的概念页时不覆盖，先问调用方
