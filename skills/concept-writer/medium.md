# 中等模式

写一篇能独立读完的 HTML 概念页。教学合同、图、公式、示例、自测、渲染都在这一档。

不跑浏览器走查，不派冷读，不交检查清单。不打开 `simple.md` 和 `max.md`。`am-render` 到 strict 警告清零是出页的一部分。

交付目标：

> 目标读者不依赖外部讲解、不阅读实现源码，只使用本页，就能完成几项明确、可观察、可检查的理解任务。调用方给了本次用点时，那些点及其依赖必须在本页（或本页所链的概念页）对得上解释。

## 职责边界

- 只拥有这一页的草稿、HTML 和 `assets/`。里程碑正文和项目实现代码不是你的文件
- 默认写成可独立阅读的概念深读：不绑死某个仓库专有名词也能懂核心机制
- 调用方给了**本次用点**或项目关系时：正文必须覆盖这些用点及其依赖，讲到够用；可用「回到项目」或文件:行号做对照。教程背景卡片仍可再链本页，但不把「代码里用到的解释」只留在外链或课文里
- 事实、代码或数据有问题：报告调用方，不用文案掩盖
- 修订既有页：先按触发问题定位断点，改草稿后整页重渲

## 教学合同（动笔前写出）

不写教学合同就不生成 HTML。

- **目标读者**：前置知识和经验边界
- **核心问题**：本页只回答一个
- **本次用点**（调用方给了就写入合同）：代码或场景里必须能对上解释的具体点
- **理解结果**：读者完成后能独立完成的 1~3 项任务。必须可观察，例如根据具体输入预测输出，指出图中符号、轴、点和轨迹的含义，解释两个表示为什么等价，判断一个常见说法为什么不成立。只能写出「了解 X」「掌握 X」「建立直觉」时，合同无效，回调用方收窄问题
- **易误读点**：读者可能把什么看成什么，页面如何消除
- **内容边界**：本次用不到的高级变体、全集手册后置到「去学」或拆页。定义、每个量的含义、基本运算、以及读懂用点所需的依赖，通常就是核心本身，不可后置到外链

开篇直接抛核心问题或具体实例，并让读者知道读完要能用本页完成什么。这是给读者的验收承诺。

## 学习链

默认按这条链组织，顺序可以按概念调整：

```text
具体对象或问题（优先对齐本次用点）
  → 读懂用点所需的依赖（就地补或链已有概念页）
  → 足够简单、可以人工检查的实例
  → 用图或交互建立变量关系
  → 引入一般定义、公式和术语
  → 预测一个新情况并验证
  → 工程边界、常见坑
  → （可选）去学：想深入时再看
```

- 先回答「它是什么、它做什么」，再比较其他方案
- 核心理解必需的推导写在正文里；依赖知识补到能接上用点为止
- 一页只建立一个核心心智模型
- 新术语首次使用时就地解释
- 类比默认不用。读者明确反馈看不懂时才用，且不替代定义，用后说明边界
- 页末可以附「去学」，链到现成教程，定位是深入学习。删掉这些链接，读者仍能完成页首承诺与本次用点的解释。该自制的图仍要自制
- 断点诊断可参考 explain-it：先判断缺的是感知经验、背景知识还是心智模型

## 图

画图前先回答：读者看完这张图，应该能说出或预测什么？答不出来就删图。

涉及空间、状态或变量关系的图，在图内或紧邻图注中写明：

- 画的是实物、坐标系、参数空间还是数据结构
- 观察方向和视角
- 坐标轴、单位和维度
- 点、线、颜色和箭头的含义
- 输入与输出的对应
- 哪些部分按比例，哪些只是符号化表达

多个面板联动时，写明共享变量和同步关系。

使用「投影」必须说明从什么空间到什么空间、保留什么、舍弃什么、屏幕方向对应什么。定义不出这个映射就不写「投影」。精确的低维切片够用时就画低维切片。仅作象征的图标注「符号示意，不用于读取几何关系」，且不承担核心推导。

位域、内存布局、时序、状态机、空间关系要配图。

## 动画与交互

- 动画必须回答一个明确问题
- 自动循环不能是唯一观察方式：需要比较多个状态时，提供暂停、重播、逐帧或变量滑块
- 给出关键状态的静态帧、当前变量值和必要结论
- 首帧必须可读
- 静态分帧更适合来回比较时就用静态分帧
- 不擅自出视频。发现视频级题材时写进返回说明，交调用方裁决

## 示例与代码

- 优先选择能心算、手算或直接观察的输入
- 每组输出只承担一个观察任务，并告诉读者看哪里
- 不把多个新概念塞进同一个最小示例
- 人为注入缩放、噪声或扰动时，写明实验条件
- 代码可运行：跑过再写进页面
- 图示或交互更适合建立当前概念时，可以先不放代码

## 自测

- 每项核心理解结果至少一道对应检查
- 至少一道读图或预测题
- 读者不能仅靠复制紧邻上文的句子完成全部题目
- 解析要解释依据

## 产出格式

- 草稿是唯一编辑对象：`docs/concepts/<slug>/<slug>.draft.md`（或调用方给的路径）。用 `bin/am-render` 整页重渲出同目录 `<slug>.html`。在 clone-from-scratch 项目里用项目的 `bin/am-render`；否则用工作区 `vendor/answer-me-with-html/scripts/am.mjs`，`--style strict`。警告不清零不出页。禁止手改 HTML，禁止 `am patch`
- 草稿格式读 `vendor/answer-me-with-html/SKILL.md`。flow/sequence 不是 mermaid：节点身份就是括号内的文本，菱形是 `{文本}`，高亮是 `*文本`。第一次写 flow 前先 `node <am.mjs> help flow`
- 自绘 SVG 用 `svg` 代码块，必须写 width 和 height。动画内嵌 SMIL，自带深色底 rect
- 自制素材落在该页的 `assets/`，用相对路径引用
- 数学公式用 LaTeX：行内 `$...$`，独立行 `$$...$$`。禁止用纯文本凑公式。代码标识符不用 LaTeX。字面 `$` 写 `\$`
- 中文直接了当。代码标识符保留原样

## 返回

- 教学合同：核心问题、目标读者、1~3 项可观察任务；若有本次用点，列出各点落在哪一节（或哪篇已链概念页）
- 每张图承担的教学任务
- 最容易误读的地方及对应处理
- 草稿和 HTML 路径
- 发现的视频级题材、存疑事实（如有）
