## 技术背景

- **主力栈：TypeScript / Node.js**（服务端开发）
- **明确不熟悉**：嵌入式 / 硬件控制、模型推理部署、音频 / 流式处理——首次用到时插背景卡片
- **大学数学已忘**（傅立叶等），不计划回炉；理解方式偏"物理直觉 + 可运行实验"，反感公式推导

## 学习目标

不是背套路，要能"知其所以然"——目标是将来能在这个领域创新、质疑既有设计。因此：① 每个"为什么"必须讲到失效边界；② 多做"破坏实验"（改参数看系统怎么坏）；③ Phase 4 的权衡复盘和检验题是重点，不能水。

## 构建环境

编译一律容器化（docker），不在宿主机装工具链；运行环境（qemu / 图形 / 键盘交互类）在宿主机。
