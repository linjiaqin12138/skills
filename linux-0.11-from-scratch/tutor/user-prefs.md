# 项目级偏好（linux-0.11-from-scratch）

> 只放本项目特有的目标与约束。

- **Rust 零基础**：实现语言定为 Rust，但用户不懂 Rust——教程中每段代码用到的 Rust 语法都要就地讲（语法卡片/脚注，按「正文主干要短」的分层规则分流）；操作系统/硬件底层概念按「明确不熟悉」对待，同样要背景卡片。
- **少造轮子（2026-10-13）**：有成熟、可 `no_std` 的 crate / 现成数据文件时优先用（例如 Limine 协议用 `limine` crate，字体可嵌 PSF）。手写协议布局仅在教学收益明确时保留；用户已表示不喜欢为协议结构重复造轮子。
- **高发图题材**：位域、内存布局、字节偏移、时序——默认出图。比如寄存器各位含义等

## 构建与验收（2026-10-28）

- **分工**：编译 / 打 ISO 在 docker 构建容器（`linux011-rust-build`，由 `make -C impl build` 等自动 `docker exec`）；qemu 与交互观察在宿主机。
- **课文验收措辞**：开篇标明用户在宿主机敲命令；写清哪一步由 make 自动进容器。只有用户必须亲自进容器 shell 时，才写 `docker exec -it …` 与工作目录；不要因为 make 内部用了 docker 就强迫用户再进一次。
