HHDM 通道 hhdm_offset + 物理地址

页表自己也在物理内存里。CPU 查表用物理地址，而 Rust 指针是虚拟地址， 所以每一步都要靠 HHDM 把「下一级表的物理地址」翻译成能写的指针。
entry_ptr = 0xFFFF800000000000 + table_physical + index*8

虚拟地址空间（HHDM 窗口）

0xFFFF800000000000 · HHDM 已覆盖的 RAM
空洞 · 没有映射
0xFFFF8000FEE00000 · LAPIC 页（要手动补）
HHDM 只覆盖内存，LAPIC 是设备寄存器，落在窗口之外——这就是必须手动改页表的原因。
