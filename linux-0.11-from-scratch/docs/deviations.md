# 偏差登记簿（铁律 8/9 台账）

状态含义：【待收敛】=功能缺失类，到预定里程碑必须补齐；【永久豁免·架构】=模块/架构差异，已写理由；【待裁决】=Phase 4 收敛验收时由用户决定对齐还是豁免。

| # | 偏差 | 类型 | 预定收敛点 | 理由/备注 |
|---|---|---|---|---|
| D1 | 架构与 boot：i386+bootsect 三段汇编 → x86_64 + Limine（直接进 64 位长模式） | 永久豁免·架构 | — | 用户 2026-10-03 明确要求抛弃历史包袱；16 位实模式 Rust 不支持。启动全过程用 docs/concepts/boot-from-power-on.md 讲（含原版 bootsect/setup 对照） |
| D2 | M0~M9 无磁盘/无文件系统 | 待收敛 | M10/M11 | 自底向上，先内核后外设 |
| D3 | M3 键盘只回显，无行规程 | 待收敛 | M13 | 先打通中断链路，行规程依赖进程与缓冲 |
| D4 | 上下文切换：原版 TSS 硬件切换 → 软件切换（保存/恢复寄存器+切栈） | 永久豁免·架构 | — | x86_64 长模式本就不支持硬件任务切换，且原版机制后来被证明是弯路（Phase 1 卡片 4）；TSS 仍保留最小用途：ring3→ring0 切栈 |
| D5 | floppy 驱动 / math 协处理器模拟 / serial 外设 / a.out 加载器不实现 | 待裁决 | Phase 4 | 目标配置下无可观察行为差异；a.out 被 ELF64 取代（卡片 B） |
| D6 | M12 前 syscall 只实现当里程碑所需子集 | 待收敛 | M15 | 逐里程碑够用即可；调用号数值对照原版 74 项表（include/linux/sys.h） |
| D7 | 文件组织按 Rust 模块树，不照抄原版目录 | 永久豁免·架构 | — | 见 phase-2 卡片 C |

| D9 | 显示：VGA 文本模式 → 线性 framebuffer + 自绘 8x16 字体；另增串口日志通道 | 永久豁免·架构 | — | 见 phase-2 卡片 D。终端 feature（转义序列、行规程）不变，只换底层显存机制 |
