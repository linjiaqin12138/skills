### 1.3 可复用的风格规则

1. **标题公式**：`今天 + 动宾短语`，句尾常留一个空格（如"今天做米塑 "），不用感叹号。
2. **内容配方**：日常小事（做饭 / 喝饮品 / 手作 / 跳舞 / 出游）+ 猫猫拟人执行，动作笨拙但认真。
3. **视觉**：9:16 竖屏、写实度极高（像实拍而非插画）、乡村中国院子或山野场景、黄金时刻侧逆光、浅景深、暖色调胶片感。
4. **主角**：固定三只猫——橘猫（大橘）、白猫（小白）、戴帽子的猫（帽帽），跨片复用同一套毛色/配饰。
5. **声音**：轻快 BGM 为主，画面几乎不靠台词；猫的拟人感来自动作本身。
6. **产出节奏**：更新频繁、单条成本低、以"陪伴感"累积粉丝。

### 2.2 声音设计

**混音链**（`compose.sh` 里可复现）：

```
原生音轨(Seedance 三镜) ─┬─→ key（闪避触发键）─┐
                         │                      ↓
后期喵声(2 处) ──────────┘            sidechaincompress(th=0.10, ratio=6)
                                              ↓ 闪避后的 BGM
森林环境音(Commons 公有领域) ─┐
原生音轨 ─────────────────────┼─→ amix → acompressor → loudnorm → alimiter
闪避后的 BGM ────────────────┘
```

- **喵喵声**：2 段取自 Wikimedia Commons 的猫叫（公有领域，`meow2.ogg` 1.1s、`meow1.ogg` 前 2.2s），分别落在 2.5s（出发后）和 11.5s（观景台）；另 3 段来自 Seedance 原生音轨。
- **环境音**：Wikimedia Commons 公有领域森林环境音（`forest.ogg`，2 分钟）铺底，音量 0.5。
- **BGM**：dollcatcher《Sometimes Mambo》（本地已有 clean 版），基础音量 0.24，开头 1.5s 淡入、结尾 2.5s 淡出。
- **闪避（ducking）**：BGM 由「原生音轨 + 喵声」作触发键，被动下潜——喵声/风声一响 BGM 自动下沉，静下来再浮回。刻意**不把常量环境音放进触发键**，否则压缩器会一直压着，BGM 被压掉 60~90% 变成听不见（已实测踩过）。
- 最终响度 **-17.3 LUFS / 真峰 -1.6 dBFS / LRA 6.0**。

> 对照版本：闪避前是「原音轨 + BGM 直接 amix」，BGM 恒定铺底、不下沉，只是被原声盖住。

## 三、已知不足与下版改进

1. **角色一致性有漂移**：Seedance 出的猫耳偏尖，耄耋的小折耳特征在动态镜头里丢失；H3-Lite 保真更好。解法是每镜都同时喂"角色定妆照 + 场景首图"两张参考图，并优先用 H3-Lite 承担特写镜。
2. **首镜收尾**：H3-Lite 第一版让猫一路走远变小，最终版把该镜截到 4.2s 规避。提示词应写"猫保持在画面中央、大小不变"。
3. **标题字**：成片加了"今天去爬山"标题字，原博主封面其实不带字；保留是为了让"作品"自带片名，若追求完全对齐可去掉（改 `compose.sh` 的 drawtext 即可）。
4. **三只猫未齐**：原博主固定三只猫出场，本次只用了耄耋单猫。要更贴风格，可补"小白 + 帽帽"两只并置镜。
5. **Ofox 偶发连接重置**：两次任务在创建阶段报 `Connection reset by peer`，重跑即成功；脚本已带任务 id 断点恢复（`*.task.json`），不会重复扣费。
