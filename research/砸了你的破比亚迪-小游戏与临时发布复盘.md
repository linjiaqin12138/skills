# 「砸了你的破比亚迪」小游戏与临时发布复盘

> 记录日期：2026-10-13
> 成品：`demo/smash-byd/index.html`（单文件，约 38KB）
> 制作：子代理 [写砸比亚迪小游戏](39124cd5-196d-4d9b-9a26-97d37ed0a420)
> 临时公网：`https://florence-booth-eligibility-libraries.trycloudflare.com/`（quick tunnel，进程停了就没）

## 1. 做了什么

女朋友父亲的台词做成 123 木头人：他没往楼下看时按住移动，和女朋友一起走向比亚迪；窗帘一动后有 0.18 秒宽限，他探头看时必须松开，否则砸车失败；走到车边上车开走即胜利。

发布方式：本机 `python3 -m http.server 8765 --bind 127.0.0.1`，再用 `cloudflared tunnel --url http://127.0.0.1:8765` 开一条不登录的 trycloudflare 隧道。公网 curl 返回 200，标题是「砸了你的破比亚迪」。

## 3. 坑

### 坑 1：安装文档还指向已经删掉的 skill

`officialskills.sh` 仍写着：

```bash
npx skills add https://github.com/openai/skills --skill develop-web-game
```

链接落在 `skills/.curated/develop-web-game`，主分支上这个目录已经不在。镜像还在 `trailofbits/skills-curated` 和 `davila7/claude-code-templates`。查 skill 要以 GitHub 当前树为准，不要信聚合站的安装命令。

### 坑 2：本机没有 cloudflared，GitHub 下载很慢

`which cloudflared` 为空。从 GitHub Releases 拉 `cloudflared-linux-amd64` 到 `/tmp/cloudflared-bin/cloudflared`，花了约 208 秒，版本 `2026.10.0`。`/tmp` 重启会丢，下次还得再下，或装到固定路径。

### 坑 3：等不到 `Serving HTTP`，服务其实已经起来了

`python3 -m http.server` 重定向到文件后标准输出是块缓冲，终端里先只有文件大小，没有 “Serving HTTP”。按横幅去等会误判没启动。用 `curl -o /dev/null -w '%{http_code}' http://127.0.0.1:8765/` 确认，当时已经是 200。

### 坑 4：隧道网址比注册完成早大约 10 秒

`cloudflared` 在 `05:47:42` 就打印了 `*.trycloudflare.com`，连接 `Registered tunnel connection` 在 `05:47:52`。中间去访问得到 **HTTP 530**，页面标题是 `Cloudflare Tunnel error`。注册完成后再请求是 200。看到网址不要立刻判失败，等日志里出现 `Registered tunnel connection` 再测。

同一次启动里还有几条可以忽略的警告：

- `lookup cfd-features.argotunnel.com ... i/o timeout`：查功能开关的 DNS 超时，会退回默认关闭，隧道仍能建。
- `Cannot determine default configuration path`：quick tunnel 本来就没有 `config.yml`。
- `Group ID 1000 is not between ping group 1 to 0`：ICMP 代理起不来，不影响 HTTP。
- UDP 接收缓冲只有 208 kiB，想要 7168 kiB：quic 的性能提示，这次没有挡住连接。

### 坑 5：quick tunnel 没有可用性承诺

不登录账号的隧道受 Cloudflare 在线服务条款约束，官方写明没有 uptime 保证，也保留调查使用权。它适合把页面丢给别人看一眼。要长期挂着，得用已登录的 named tunnel。本机 `cloudflared` 或 `python3 -m http.server` 一停，公网地址立刻失效。

## 4. 没做完的验证

子代理用抽出的脚本跑过 `node --check`，并用模拟确认宽限、被看时移动失败、站住能熬过、走到车边胜利。公网只核对了 HTTP 200 和标题，没有在浏览器里从头玩一局。
