## 覆盖的四个问题

1. **工具栈**：除 Claude Code、Cursor 外还有哪些；为何好用；具体功能/工作流  
2. **公开看法与实践**：博客、演讲、播客、论坛；做什么；如何提效；为何有效  
3. **人机协同痛点**：幻觉、上下文丢失、review 成本、一致性、权限/安全、过度依赖及对策  
4. **RSI 飞轮**：优先 = Recursive Self-Improvement（用 AI 改进工作流）；另义单独标注。种子案例：**土豆姐 / pstack**
