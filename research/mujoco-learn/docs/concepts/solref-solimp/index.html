参数

solref = (timeconst, dampratio)
solimp ≈ (d0, dmax, width)

正格式：k ∼ 1/timeconst²，b ∼ 2·dampratio/timeconst； 阻抗 d(r) 在穿透 0→width 间由 d0 过渡到 dmax，力乘 d。 穿透在画面上放大了约 2.5×，便于看见。
